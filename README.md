# clef-finetuning

**Decide, don't generate.** Fine-tuning Cloudflare's open-weight [Clef](https://huggingface.co/Cloudflare/clef-flash)
decision model on a single 12 GB GPU for real-time entity resolution, compared against generative models trained
with Hugging Face [TRL](https://huggingface.co/docs/trl).

> Status: early development. Nothing is trained yet. See [PLAN.md](PLAN.md) for the full plan.

## Quickstart

Requires [uv](https://docs.astral.sh/uv/) and a CUDA GPU (developed on an RTX 3060, 12 GB).

```bash
make setup      # create the environment
make test       # CPU tests
make validate   # check all experiment configs
make e0c        # run an experiment by id (see configs/experiments/)
```

## Layout

| Path | Contents |
| --- | --- |
| `configs/` | Experiments (one file per id E0a-E8), datasets, models (pinned revisions), hardware profiles |
| `src/clef_finetuning/` | `data`, `schema`, `models`, `cache`, `train`, `eval`, `serve` |
| `src/clef_finetuning/models/clef_upstream/` | Cloudflare's model code, vendored unmodified |
| `scripts/` | Entry points: run experiments, validate configs, download data |
| `results/` | Small committed metrics per experiment and the scoreboard |
| `articles/` | One folder per article: reproduce commands and figures |
| `tests/` | CPU tests; `make test-gpu` runs GPU-marked tests |

Datasets, model weights, activation caches and checkpoints are never committed. Trained adapters are published
on the Hugging Face Hub.
